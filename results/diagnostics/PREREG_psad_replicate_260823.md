# 사전등록 — 3-f: PSAD 복제 실행 (같은 기계·같은 시드 재학습)

**작성 시각: 2026-08-23 · 실행 전. 이 문서를 커밋한 뒤에 돌린다.**

관련 `docs/260823_psad_variance_decomp.md` · `docs/260823_psad_3way_compare.md`

## 0. 왜 사전등록하나

3-f 는 앞선 두 문서가 **저지른 실수를 고치는** 실험이다. 3자 대조는 분기 점수 divergence 의
원인을 "기계마다 cuDNN 알고리즘 선택이 다르다" 고 **재지 않고 적었고**, 재보니 틀렸다
(시드만 바꿔도 같은 divergence 가 나온다). 같은 실수를 반복하지 않으려면 이번엔
**결과를 보기 전에 판정 규칙을 고정**해야 한다.

특히 이 실험은 "결과가 어느 쪽이든 이야기를 만들 수 있는" 종류다 —
`≈1.0` 이면 "시드가 실행을 고정한다", `≈0.94` 면 "학습이 비결정적이다" 로 둘 다 말이 된다.
그래서 **어느 값이 어느 결론인지 미리 못박는다.**

## 1. 무엇을 돌리나

```
SEED_TAG=42rep2 bash scripts/psad_rebuild/train_unet_seeds.sh 42
```

- 5범주 × **seed 42** × 1회 재학습 (300ep, lr 1e-3, scratch) — 3-d 와 **완전히 같은 명령**
- **같은 기계**(이 5090), 같은 코드, 같은 의사레이블, 같은 shim
- 다른 것은 **실행 시점 하나뿐**이다
- 출력은 `unet_seed42rep2/` 로 분리 — 정본·기존 재구축본을 덮지 않는다
- 이어서 `score_psad.py` 로 채점 (`PSAD_SCORE_OUT=reports/countgd/psad_rebuild_5090_rep2`)
- 비용 ≈ 36분 × 5 = **3시간**

**설정 탐색은 없다.** 하이퍼파라미터·정규화·가중치 어느 것도 건드리지 않는다.
범주는 5개 전부 돌리고 **전부 보고**한다(잘 나온 것만 고르지 않는다).

## 2. 무엇을 재나

3-f 가 채우는 것은 표의 빈 칸 하나다.

| 비교 | 다른 것 | 기존 측정 |
|---|---|--:|
| cross_seed | 시드 | Spearman **0.9381** (30쌍) |
| cross_rebuild | 기계 + 실행 | **0.9378** (15쌍) |
| cross_both | 전부 | **0.9374** (30쌍) |
| **cross_replicate** | **실행 시점만** | ← **이번에 잰다** (5쌍) |

지표는 앞과 동일 — 범주별 Spearman·Kendall τ, 분기 L+S 절대차, 그리고 융합 L+S.

## 3. 판정 규칙 (실행 전 고정)

`R` = cross_replicate 평균 Spearman (5범주). 기준선 `S` = cross_seed 0.9381.

| 조건 | 판정 | 함의 |
|---|---|---|
| **R ≥ 0.99** | **(B) 결정적** | 기계 안에서는 시드가 실행을 고정한다. 그러면 기계 효과가 실재하며 3자 대조의 원래 서술이 (귀속 근거는 부실했어도) 결과적으로 맞다 |
| **\|R − S\| ≤ 0.02** | **(A) 비결정적** | 학습이 애초에 비결정적이다. 시드 고정이 재현을 보장하지 않는다. 재현성 주장의 조건은 "다른 기계에서" 가 아니라 **"다시 학습하면"** |
| 그 사이 (0.958 ≤ R < 0.99) | **(C) 혼합** | 시드가 부분적으로 작동하고 실행·기계가 추가 변동을 만든다. 양쪽을 다 보고하고 어느 쪽도 단정하지 않는다 |

경계가 겹치면 **더 보수적인 쪽**(C)으로 읽는다.

부수 판정 — 융합 L+S 의 복제 간 차가 시드 std(0.0011) 이내인가.
이내면 "융합은 재학습에 대해 안정" 이 복제 축에서도 확인된다.

## 4. 등록하는 예측

**(A) 가 나올 것으로 예측한다** (R ≈ 0.93~0.95).

근거 — cross_both(0.9374)가 cross_seed·cross_rebuild보다 **더 낮지 않다**. 두 교란이 각각
실재하고 독립이라면 겹쳤을 때 divergence 가 커져야 하는데 그렇지 않다. 이는 **어떤 교란이든
같은 바닥에 포화**한다는 뜻이고, 그렇다면 "실행 시점만 다른" 교란도 같은 바닥에 닿을 것이다.

기전 후보 — `train_normal_unet.py` 212행 `cudnn.benchmark = True`. 합성곱 알고리즘을 실행
시각 측정으로 고르므로 같은 기계에서도 선택이 달라질 수 있고, 선택된 알고리즘 상당수가
backward 에서 `atomicAdd` 를 써 누적 순서가 실행마다 다르다.
`torch.use_deterministic_algorithms` 는 설정돼 있지 않다.

**이 예측이 빗나가면 그대로 기록한다.** 260822 계층 사전등록에서 예측 2건이 모두 빗나갔고
그것을 적었다(`docs/260822_layer_prereg_result.md`). 같은 규약이다.

## 5. 3-f 가 답하지 **않는** 것

- **비트 단위 결정성 복원 가능 여부** — `cudnn.benchmark=False` +
  `use_deterministic_algorithms(True)` 로 고정되는지는 별도 문제다. (A) 가 나오면 3-g 로
  검토하되, 그것은 PSAD **공식 코드를 바꾸는 것**이라 재구축의 성격이 달라진다는 점을
  먼저 판단해야 한다. 이번 사전등록 범위 밖이다.
- **원본 hc(소실본)와의 1.08pp 격차** — 원본이 없어 어떤 실험으로도 직접 답할 수 없다.
  3-f 는 "독립 재구축 간 산포가 어느 정도인가" 를 줄 뿐이고, 그 산포로 1.08pp 를
  설명할 수 있는지는 별개 논증이다.
- **논문 헤드라인의 변경** — 3-f 는 어느 결과가 나오든 **정본 수치를 바꾸지 않는다.**
  재현성 서술의 **문구**만 정한다.

## 6. 종결 조항

3-f 는 이 질문에 대한 **마지막 실험**이다. R 이 (C) 로 나와도 다시 조건을 바꿔 재실행하지
않는다 — 원하는 답이 나올 때까지 반복하면 그건 측정이 아니라 선택이다.
(C) 면 "혼합, 단정 불가" 로 보고하고 끝낸다.
