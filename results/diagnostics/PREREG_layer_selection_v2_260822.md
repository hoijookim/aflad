# 사전등록 v2 — 계층 선택, **마지막 시도** (260822, 5090)

**실행 전에 고정한다.** 결과를 보고 규칙을 바꾸지 않는다. **test 는 어느 단계에서도 열지 않는다.**

선행: v1 = `PREREG_layer_selection_260822.md` (`7cb0f1b`) · 결과 `docs/260822_layer_prereg_result.md` (PR #84)

## 0. 이 문서의 가장 중요한 조항 — **이번이 마지막이다**

계층 선택을 test 없이 정하려는 시도는 **v2 로 종결한다.** v2 가 다시
`NO_SINGLE_WINNER` 를 내면 **더 이상 기준을 바꾸지 않고**, 결론은
"train/val 만으로는 계층이 결정되지 않는다" 로 확정하고 **A(선언 규칙 + 민감도 보고)** 로 간다.

이 조항이 필요한 이유는 명백하다. 기준을 바꿔가며 반복하면 **언젠가는 L17 이 이긴다.**
그것은 test 를 안 봤을 뿐 같은 종류의 선택 편향이고, 0.9807 사건의 변형이다.
**시도 횟수를 미리 못박는 것이 유일한 방어다.**

## 1. v1 을 왜 고치는가 — 결과와 무관한 근거만

v1 판정은 `NO_SINGLE_WINNER` 였고 그 직접 원인은 통제군 `global_photo` 에서 L17 이 꼴찌였다는
것이다. 그러나 **그 통제군의 결함은 판정 전에 지적했다**(로그·커밋 순서로 확인 가능).

| v1 문제 | 왜 문제인가 (결과와 무관한 근거) |
|---|---|
| `global_photo` 가 **부호가 뒤집힌 지표** | LOCO 구조 이상은 **국소 결함**이다. 전역 밝기·대비 이동은 이 분기가 잡아야 할 대상이 **아니라** 잡지 **말아야** 할 교란이다. 세 계층 전부 우연 수준(0.53~0.59)인 것이 그 방증이며, 높을수록 좋다고 채점한 것이 설계 오류다 |
| `paste`·`fill` **포화** (폭 0.038·0.022) | 섭동이 너무 쉬우면 계층을 가르지 못한다. 실질 변별력은 `blur`(0.095) 하나뿐이었다 |
| **동점 처리** 미정의 | 표준(평균 순위) 미적용. v1 에서는 승자 불변이었으나 규칙 자체는 고쳐야 한다 |

## 2. 무엇이 달라지는가 — **한 눈에**

| | v1 | v2 | 근거 |
|---|---|---|---|
| 통제군 | `global_photo` **채점 포함** | **채점에서 제외**, 불변성 관찰로만 보고 | 교란 축이지 목표 능력이 아니다 |
| 통제군 부호 | 높을수록 좋음 | **부호를 뒤집지 않는다** — 아예 순위에서 뺀다 | 뒤집으면 L17 의 패배가 승리로 바뀐다. 그렇게 얻은 승리는 못 쓴다 |
| 난이도 | 단일 강도 → 포화 | **강도 3단(weak/med/strong)** 전부 채점 | 보정 대신 곡선 전체를 보고한다 — 튜닝 여지를 없앤다 |
| 경계 다양성 | paste/blur/fill | + **`warp`(경계 없는 국소 변형)** | v1 통제군이 하려던 일("경계 오염 없는 국소 이탈")을 제대로 하는 계열 |
| 동점 | 미정의 | **평균 순위** | 표준 |
| 재시도 | 없음 | **v2 가 마지막** | §0 |

> **`global_photo` 를 지우지 않는다.** 계속 측정하고 결과를 싣되 **순위에서 뺀다.**
> 불리한 계열을 삭제한 것이 아니라, 재는 대상이 다르다는 것을 명시하는 것이다.

## 3. 고정하는 설계

### D1 — 후보
`{L8, L17, L23}`. 캐시 보유분. 집합은 `extract_dinov2_l_336.py:24` 의 위계 표본이라 test 무관.

### D2 — 측정 (v1 과 동일, 검증됨)
뱅크 = train 정상 50,000 패치(`default_rng(seed)`) · 정상 측 = **val 정상**(캐시) ·
이상 측 = val 정상에 섭동 후 **재인코딩**(336 BICUBIC, ImageNet norm, `h[0,5:,:]`) ·
점수 = 패치 1-NN L2 공간 최댓값 · 지표 = AUROC.

> val 을 정상 측에 두는 이유는 train 이면 뱅크 자기매칭 LOO 가 필요한데 그 누락이 실제
> 버그였기 때문이다(`20d1a92`).

### D3 — 채점 계열 4종 × 강도 3단 (전부 **국소 구조 이탈**)

| 계열 | 내용 | 경계 | weak / med / strong |
|---|---|:--:|---|
| `paste` | 같은 범주 train 정상의 사각 패치 | 단단 | 면적 1% / 2.5% / 6% |
| `fill` | 국소 영역을 영역 평균색으로 | 중간 | 면적 1% / 2.5% / 6% |
| `blur` | 국소 가우시안 흐림 | 부드러움 | 커널 5 / 11 / 17 (면적 4%) |
| **`warp`** | 국소 탄성 변형(내용 보존, 붙이기 없음) | **없음** | 변위 2 / 4 / 7 px (면적 6%) |

`warp` 가 v1 통제군의 대체다 — **경계 아티팩트 없이** 국소 구조가 어긋나므로, 이 분기가
잡아야 할 대상 그대로다.

### D4 — 관찰 전용 (채점 제외)
`global_photo` (전역 밝기·대비 이동, 강도 3단). **순위에 넣지 않는다.**
값은 표에 싣고 "낮을수록 교란에 강함" 으로 **서술만** 한다.

### D5 — 시드
{42, 43, 44}, `default_rng(seed)` 결정적 생성. 채점 = 4계열 × 3강도 × 5범주 × 3시드.

## 4. 판정 규칙 — 실행 전 확정

1. (계열, 강도) 12개 칸마다 3시드·5범주 평균 AUROC 로 계층 순위. **동점은 평균 순위.**
2. **주 판정 = 12칸 평균 순위 최고 계층.**
3. **안정성 요건**: 그 계층이 **어느 계열에서도**(강도 3단 평균 기준) 꼴찌가 아닐 것.
4. **포화 배제**: 어떤 칸의 세 계층 최댓값이 **모두 > 0.995** 면 그 칸은 정보가 없으므로
   **순위 계산에서 자동 제외**하고, 제외 사실을 보고한다. (v1 의 포화 문제를 규칙으로 흡수)

### 결과별 처리 (미리 선언)

| 결과 | 처리 |
|---|---|
| 승자 = **L17** | 현행 주 설정에 **사전 기준 근거가 생긴다.** §3.1.2 에 기준·표를 싣고, v1 이 결정 불가였다는 사실도 함께 적는다 |
| 승자 = **L8 / L23** | **그대로 보고한다.** 주 설정 교체는 저자 판단이며 이 사전등록은 교체를 자동 실행하지 않는다 |
| **NO_SINGLE_WINNER** | **종결.** 더 시도하지 않고 A 로 간다(§0) |

**test AUROC(L8 0.9656 / L17 0.9723 / L23 0.9670)는 이미 알고 있다.**
일치가 정답의 근거가 아니고, 불일치가 기각의 근거도 아니다.

### 사전 예측 (기록용, 판정 근거 아님)

v1 에서 `blur` 가 유일하게 변별력을 보였고 거기서 L17 이 뚜렷했다(0.8991 대 0.8038/0.8053).
`warp` 도 국소 구조 이탈이므로 **L17 이 유리할 것**으로 본다. `paste` 는 weak 강도에서
포화가 풀리면 얕은 계층이 따라붙을 수 있다.
v1 예측은 **둘 다 빗나갔으므로**(`global_photo`→L23 예상, 실제 L8 / `paste`→L8 예상, 실제 L17)
이 예측의 신뢰도도 낮게 본다.
