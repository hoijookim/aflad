# [논문 인계] 260821 — DINOv3-L 파라미터 수: 어느 쪽이 맞나

**답: §4.5 의 303M 이 맞다. 그런데 문제는 그 한 칸이 아니다.**

전부 실측했다. 산출물 `reports/countgd/param_counts_measured.json` ·
코드 `scripts/psad_rebuild/measure_param_counts.py` (재실행 가능).

---

## 1. 표 C1 은 5칸 중 4칸이 실측과 다르다

| 모델 | 실측 | 반올림 | **논문 표 C1** | |
|---|--:|--:|--:|:--|
| DINOv3-S/16 | 21,596,544 (21.60M) | **22M** | 21M | ✗ |
| DINOv3-B/16 | 85,660,416 (85.66M) | **86M** | 86M | ✓ |
| DINOv3-L/16 | 303,129,600 (303.13M) | **303M** | 300M | ✗ |
| DINOv2-B/14 | 86,580,480 (86.58M) | **87M** | 86M | ✗ |
| DINOv2-L/14 | 304,368,640 (304.37M) | **304M** | 300M | ✗ |

**표 C1 은 실측표가 아니라 계열 명목 표기(S≈21M / B≈86M / L≈300M)다.**
그 증거가 DINOv2-B 다 — 실측 86.58M 은 87M 으로 반올림되는데 표는 86M 이라, 실측을 반올림한
값일 수 없다. DINOv3-B 한 칸만 우연히 맞았다.

즉 **"두 곳이 어긋난다"가 아니라 "논문이 한 모델에 두 관례를 쓰면서 그걸 밝히지 않았다"** 이다.
§4.5 는 실측, 표 C1·§3·§4.2·결론은 명목이다.

## 2. §4.5 는 고칠 것이 없다 — 네 값 모두 실측과 맞는다

| §4.5 표기 | 실측 |
|---|--:|
| 재구성 8.1M | 8,057,856 = **8.06M** (teacher 2.69 + student 4.27 + AE 1.10) |
| 패치 메모리 backbone 303M | 303,129,600 = **303.13M** |
| 구성 분기 약 171M | 171,435,856 = **171.44M** (WRN-101-2 126.89 + ResNet-101 44.55) |
| 합 약 482M | **482.62M** |

구성 분기 실측은 분할 인코더 + 임베딩 backbone 만이라 합성곱 디코더·좌표 채널이 빠져 있다 —
논문의 "약 171M" 이 그만큼 보수적이다. **메모리 각주는 실측 분해이므로 이대로 두는 게 맞다.**

## 3. 권고 — 표 C1 쪽을 실측으로 옮긴다

명목을 남기고 §4.5 만 300M 으로 낮추는 선택지는 두 가지 이유로 권하지 않는다.

1. **합이 틀어진다.** 482M 은 실측 합이다. 300M 으로 바꾸면 479M 이 되고, 실제 메모리를
   잘못 보고하게 된다.
2. **명목 표기가 실질을 가린다.** 표 C1 은 DINOv2-L 과 DINOv3-L 을 **둘 다 300M** 으로 적는데
   실제로는 304.37M vs 303.13M 로 **DINOv2-L 쪽이 크다.** 300M/303M 만 고치면 표가
   "DINOv3-L(303) > DINOv2-L(300)" 이라고 말하게 되어 **대소가 뒤집힌다.** 지금은 두 칸이
   같아서 드러나지 않던 문제다.

논문이 "원논문 수치는 참고로만, 모든 값은 본 환경 실측" 이라는 태도를 일관되게 취하고 있으므로,
파라미터 열도 실측으로 두는 편이 그 태도와 맞는다.

### 깨지지 않는 것

- **"약 14배 파라미터 범위"** (§4.2·결론): 304.37 / 21.60 = **14.09배**. 그대로 유효하다.
  (명목으로도 300/21 = 14.3 이라 어느 쪽이든 "약 14배" 다.)
- **§4.5 의 482M·지연·VRAM** 전부 불변.
- 표 C1 의 AUROC 열은 손대지 않는다 — 파라미터 열만이다.

## 4. 덧붙임 — 이 건은 "근거 없는 수치" 계열이 아니다

이번 세션에서 걷어낸 것들(가산적, 모든 방법 중 가장 작다 …)은 **데이터가 지지하지 않는
주장**이었다. 이건 다르다 — 두 값 다 실재하는 수치이고, 문제는 **어느 관례인지 말하지 않은
것**이다. 그래서 문장을 지우는 게 아니라 숫자를 맞추는 것으로 끝난다.
